# Platform Analysis Table

| Aspects | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| **Main language** | HTML5 | C++ | C# |
| **Architecture** | any | x86, x86_64 | ARM64 |
| **Distribution method** | Web Browser / URL (SaaS / Web App) | Native Installer / Executable (`.exe`, `.msi`) | App Stores (Google Play Store, Apple App Store, `.apk`/`.aab`) |
| **Advantage** | Kompatibilitas cross-platform tanpa installasi, maintainance mudah dan update instant untuk semua pengguna | Proses performa tinggi dengan full akses ke hardware pengguna | Portable, akses touch-screen dan sensor mobile (GPS, camera, accelerometers) |
| **Disadvantage** | Akses hardware resource terbatas dan sangat bergantung pada koneksi internet | Ukuran file besar, akses bergantung pada kompilasi untuk setiap OS dan spesifikasi | Thermal/Battery terbatas dan performa hardware yang ketat |
| **App example** | THE iDOLM@STER: Shiny Colors (enza) | Minecraft Bedrock Edition | Uma Musume: Pretty Derby |
